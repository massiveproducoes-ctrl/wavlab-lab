# Ícones das insígnias

Cada insígnia usa um arquivo `<icon>.svg` desta pasta; `<icon>` é o valor da coluna `badges.icon` no banco
(só letras minúsculas, números e hífen).

Para criar um ícone novo:
- `viewBox="0 0 24 24"`, legível em 16 px (formas grandes, sem traço fino).
- Paleta do site: laranja `#ff5500` e fundo escuro `#0b0b0d`. Sem emoji e sem texto dentro do desenho.
- Salve aqui, cadastre a insígnia no banco com `icon = '<nome do arquivo sem .svg>'`.
